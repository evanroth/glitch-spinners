Spinnerz

Broken, glitched spinner text for Claude Code. No words.

Made by Evan Roth · Code on GitHub

~ $ cat README

While Claude Code works, it shows a word next to the spinner: Jogging…, Pondering…. This swaps those words for 200 lines of corrupted noise: stacked zalgo marks, dripping box-drawing, runes, mojibake, error debris, emoji, flags that don't exist. All 200 are filling the background of this page.

Each line was bred, not written. A gallery of about 30 glitch effects (combining marks, math alphabets, lookalike letters, rotting braille, torn and smeared text) mixed and mutated them, and Evan rated them by hand over a few rounds. The ones he kept were frozen into the plain text that Claude Code can show, each long enough to fill an 80-column terminal. Claude adds its own spinning glyph and shimmer.

install

Paste this into Terminal:

curl -fsSL https://raw.githubusercontent.com/evanroth/glitch-spinners/main/install.sh | bash

Then start a new Claude Code session. Sessions already running keep their old words until you restart them.

The installer backs up ~/.claude/settings.json, then adds the strings to it. Your other settings stay as they are. It needs jq, which comes with recent versions of macOS (on Linux: sudo apt install jq).

To mix these in with Claude's usual words instead of replacing them:

curl -fsSL https://raw.githubusercontent.com/evanroth/glitch-spinners/main/install.sh | bash -s -- --append
~ $

update

Run the install command again. It swaps in the latest list.

curl -fsSL https://raw.githubusercontent.com/evanroth/glitch-spinners/main/install.sh | bash
~ $

uninstall

Removes the strings (after another backup), and Claude goes back to its own words.

curl -fsSL https://raw.githubusercontent.com/evanroth/glitch-spinners/main/uninstall.sh | bash
